# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- `padding` config: gap between badge and image edge as a fraction of the badge width. The default `0.25` restores the 0.1.0 spacing; `0` keeps badges flush.

## [0.1.1] - 2026-10-15

### Changed

- Badges sit flush with the image edge. Spacing comes from transparent margin in the badge PNG.

## [0.1.0] - 2026-08-10

### Added

- Editorial AI label field for Statamic assets.
- EU AI badge watermarks for Glide derivatives, cache-busting URLs, and CP thumbnails.
- Bard and template-controlled media labels with accessible markup.
- Coverage table documenting covered and operator-action delivery paths.
